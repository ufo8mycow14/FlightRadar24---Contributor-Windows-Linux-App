# Third-party components

The project-authored controller/UI and documentation use GNU GPL v3 or later (see `COPYRIGHT` and `LICENSE`). Third-party components retain their own terms. This independent project is not an official Flightradar24 release.

**Public distribution scope:** the Git source tree supplies project source, tests, documentation, OurAirports reference data, the legacy Leaflet asset/licence and selected native source patches. GitHub Releases separately supplies the Windows x64 receiver installer and matching source archives. The public installer excludes the proprietary feeder executable; an optional setup task downloads it unchanged directly from Flightradar24. Private operational records and profiles are excluded. The table below inventories the development/runtime components. Paths beginning `runtime/` describe the installed package, and the current public companion archive is documented in [release information](docs/RELEASE.md).

The project-authored `frw-pty` supervisor and generated guest probe helpers are supplied under the MIT licence with source and licence text in `work/source-delivery`. The supervisor's Cygwin runtime dependency uses the existing Cygwin licence and linking exception described above. The generated guest helpers implement only the documented discovery probes; they are not Bash or general Linux process tools.

The decoder's top-level MIT notice does not replace the separate licences in its compiled dependencies. The 0.6.4 corresponding-source release contains the exact full decoder archive and current patch, matching runtime sources and current controller/helper build instructions. Its explicitly Tor-derived smartlist code has the upstream BSD licence and smartlist copyright notice under `runtime/licences/decoder-components`; the ZIP wrapper's supplementary upstream MIT licence remains there too. The supplementary notices do not claim that these Windows ports are byte-identical to upstream files.

The Windows application uses native Qt Widgets, Qt Network and QPainter; it does not launch or bundle a browser or Qt WebEngine. Qt's shared libraries and platform plugin are shipped as separate replaceable files in the one-folder package. The native map requests tiles only as the user views geographic areas; its bounded disk cache is in the app's user profile.

The public controller/UI source is openly reusable under its declared GPL licence. The Windows release includes source access and dependency notices; its optional vendor-download path keeps the proprietary feeder out of the published binary package. A project's source licence cannot grant rights over another vendor's software. The release source index is `docs/RELEASE-SOURCES.json`; corresponding sources are downloadable from the same release page as the installer.
## OurAirports offline reference

The native application includes a reduced airport reference from David Megginson's OurAirports open-data repository, commit `845fd124acca9a13d076f3ab957d3eecf46721fc`, captured 17 November 2026. It includes 5,282 large and medium airports for offline code/name/coordinate search. The repository's `LICENSE` dedicates the data to the public domain under the Unlicense; the exact licence is bundled at `frw/data/ourairports-LICENSE.txt`. Provenance and source/licence SHA-256 values are in `frw/data/airports-provenance.json`. The upstream source is https://github.com/davidmegginson/ourairports-data . Reference data has no accuracy/fitness warranty and is not a navigation database. Airport proximity observations do not establish routes or airport movements.

## Historical aviation waypoint reference

`frw/data/waypoints-au.json` is an Australia-region geographic subset of Robin A. Peel’s FlightGear `Navaids/fix.dat.gz`, data cycle 2013.10, upstream file commit `e6c31a1942262085021e5952f7a48e1063c9419a`. The original copyright/licence notice, immutable source URL, source SHA-256, bounds and modification notice are retained in the JSON. Copyright © 2013 Robin A. Peel; GPL version 2 or later. The full GPL v2 is included at `frw/data/WAYPOINTS-GPL-2.0.txt`. The editable JSON and reproducer `scripts/prepare-waypoint-reference.py` are included in the public application source archive. The subset/conversion was made by FlightRadar24 contributors on 26 November 2026. These are historical reference coordinates, not a current AIRAC feed. Source: https://gitlab.com/flightgear/fgdata/-/blob/e6c31a1942262085021e5952f7a48e1063c9419a/Navaids/fix.dat.gz .
