Connect your receiver

Use a supported RTL2832U USB radio with an R820T/R820T2 tuner, or connect to an existing Beast or AVR stream.

Input

Device names will appear here after a scan. Use the decoder index to choose between multiple radios.

USB reception requires a compatible WinUSB driver. Zadig driver tool ↗. Select the SDR’s bulk interface, usually Interface 0. Driver installation is a separate Windows action.

Tuning

Gain −10 selects automatic gain. Bias tee supplies power to compatible antenna hardware; enable it only when your setup requires it.

Antenna location

Used for local plotting and position checks. Enter the same antenna position during official Flightradar24 registration.

Stop reception before changing settings.

Feed Flightradar24 from this PC

The Windows receiver passes live data to the unchanged official feeder, which connects to Flightradar24 using its own upload protocol.

Check feeder connection and aircraft sent in Station health, then confirm recent activity in your Flightradar24 account. MLAT has its own status and requires service approval. The bundled Windows compatibility runtime remains experimental.

Upload & MLAT

MLAT needs accurate sample timestamps, a correctly registered station position and Flightradar24 server approval. AVR inputs without timestamps cannot provide MLAT. After service approval, MLAT also needs sufficient reception and nearby participating receivers.

Output streams
RAW/AVR carries raw frames; SBS carries decoded aircraft reports; Beast carries binary frames with receiver timestamps. Beast output needs a timestamped input. LAN access applies to data streams only; the control interface always stays local.
Operation
Automatic start means when this app opens. This package does not install a Windows service or change Windows startup.
Enabled output ports must be different.

  
Import a Pi fr24feed.ini
Preview the conversion before applying it. Unsupported options remain in the original settings for reference and export; they are listed explicitly and are not silently executed.

  
Compatibility boundaries
  • Local RTL-SDR reception is for 1090 MHz ADS-B and Mode S. A compatible tuner, driver and antenna are required.
  • Beast TCP/serial and AVR TCP/serial inputs are available. Decoded SBS TCP is available for local display and SBS output.
  • The Pi image also includes 978 MHz UAT and Kinetic SBS binary/MPX options. Those protocols are not implemented in this Windows build.
  • Pi Wi-Fi setup, Linux device paths, system updates and operating-system shutdown are replaced by Windows controls.
  • This independent app is not an official Windows release from Flightradar24.
